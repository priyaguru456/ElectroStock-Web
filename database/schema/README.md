# Schema

Database design and schema documentation for ElectroStock (MySQL).

This is a companion to the authoritative Prisma schema at
[`backend/prisma/schema.prisma`](../../backend/prisma/schema.prisma) — use this
folder for things that don't belong in the `.prisma` file itself, e.g.:

- ER diagrams
- Table/field descriptions and rationale
- Indexing and normalization notes
- Design decisions and trade-offs

Do not duplicate Prisma model definitions here.
